# Hjälpguiden Stockholm

En statisk webbsida som hjälper personer i hemlöshet i Stockholm att hitta var de kan sova, äta, duscha och få hjälp just nu, och som hjälper allmänheten att agera rätt.

- Inga konton, inga cookies, ingen spårning.
- Fungerar utan JavaScript och offline efter första besöket.
- All platsdata ligger i `data/` med källa per post. Se `data/README.md`.

```bash
npm install
npm run dev
npm test
npm run build
```

Mer i `CLAUDE.md`.
